# Изменения

## 1.0.1 — 2026-10-22

- Добавлен подтверждённый адрес Vivox `85.236.105.136/32`: текущие DNS и соединение самого Foxhole показали новый сервер вместо адресов, перечисленных в 1.0.0.
- Сохраняются первоначальные исключения `85.236.98.180/32` и `85.236.98.181/32`.
- Добавлена проверка обновления состояния 1.0.0: старые маршруты сохраняются, новый адрес добавляется один раз.
- Обновлены инструкции: после изменения маршрутов может потребоваться полный перезапуск Foxhole.
- После применения нового исключения и перезапуска пользователь подтвердил работу голоса с включённым Happ.

Список IP статический; автоматического обновления по DNS нет. Полная установка пакета и автозапуск после реальной перезагрузки пока не проверены.
